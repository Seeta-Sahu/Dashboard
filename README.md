# 📊 Madhav Ecommerce Sales Dashboard

## 📝 Project Overview
An interactive **E-commerce Sales Dashboard** created using Power BI to visualize and analyze sales data.

## 📂 Project Files
- 📄 Two CSV files containing the dataset.
- 🖼️ One JPG image used as the dashboard background.

## 🖥️ Dashboard Preview

![Madhav Ecommerce Sales Dashboard](Dashboard.png)

## 📈 Dashboard Highlights
- 💰 Total Sales Amount
- 📦 Total Quantity
- 💹 Total Profit
- 🛒 Average Order Value (AOV)
- 🌍 State-wise Sales Analysis
- 🏷️ Category-wise Quantity Analysis
- 📅 Monthly Profit Analysis
- 👥 Customer-wise Quantity Analysis
- 💳 Payment Mode Analysis
- 📊 Sub-category-wise Profit Analysis
